Install

git clone https://github.com/NickGhignatti/ambitwin.git
cd ambitwin
just setup install
StepWhat happens
2mise downloads each tool in .mise.toml that is missing
4moon reads .moon/workspace.yml and starts every project’s deps task
5Node: npm ci. Python: uv sync --locked. Rust: cargo fetch. Go: go mod download
  • No step rewrites a lockfile, so an install on macOS or Windows cannot break CI.
  • MOON_CONCURRENCY=2 just setup install caps the parallel tasks on a small machine.
  • Lockfiles, and why Node locks are made for Linux: Dependencies & Security.

The .env file

just stack env

Eleven POSIX sh scripts in scripts/env/ run in order. Each one writes only a value missing from .env, so a second run changes nothing. just stack dev and just stack start run it first anyway.

ScriptWritesUsed by
create.shAn empty .env, if none existsevery other script
vapid.shVAPID_PUBLIC_KEY, VAPID_PRIVATE_KEY, VITE_VAPID_PUBLIC_KEYnotification, frontend
token.shEVAL_JWT_SECRET, 256-bit hexagent evaluation runs
config.shBACKEND_PORT (80), FRONTEND_PORT (8080), DEV_URL (http://localhost), and asks for OPENROUTER_API_KEYCaddy, frontend, agent
langfuse.shLangfuse keys, its first-boot admin, the agent’s trace exporter settingsLangfuse, agent
keycloak.shKEYCLOAK_ADMIN_USER (admin), KEYCLOAK_ADMIN_PASSWORD, KEYCLOAK_DB_PASSWORD, empty GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRETKeycloak
controlplane.shINTERNAL_SIGNING_SECRET, TENANCY_DB_PASSWORD, REGISTRY_DB_PASSWORDthe four Go services
gateway-key.shA 2048-bit RSA key in secrets/gateway-dev-key.pem, not in .envclaims-gateway
ingest-key.shTELEMETRY_DEVICE_MASTER_KEY, TELEMETRY_INGEST_SECRETtelemetry, simulators, ap-collector
telemetry-db.shTELEMETRY_DB_PASSWORDthe cluster only: Compose uses the fixed password telemetry
rust.shRUST_VERSION, copied from .mise.tomlthe rust-base image build

What some of these values mean:

  • OPENROUTER_API_KEY is the only question the chain asks. Empty is fine: agent starts, and the first question to the assistant fails. Keys: https://openrouter.ai/keys. GOOGLE_API_KEY and DEEPSEEK_API_KEY are read as the same key.
  • INTERNAL_SIGNING_SECRET must be one value for all four Go services: each signs or checks the others’ calls with it.
  • TELEMETRY_DEVICE_MASTER_KEY makes every building’s device key. Losing it locks out every collector.
  • TELEMETRY_INGEST_SECRET signs for any building. Simulators need it. A real site never gets it.
  • The gateway key lives in a file because a PEM key spans many lines and a .env value cannot. With no file, claims-gateway makes a new key at each start, and every open session dies.
  • Langfuse opens at http://localhost:3030, user admin@ambitwin.local, password langfuse-admin. Without OTEL_EXPORTER_OTLP_ENDPOINT, agent prints its traces to the console instead.

Example: a new key. A teammate loses their VAPID keys:

sed -i '/^VAPID_\|^VITE_VAPID_/d' .env   # drop the three lines
sh scripts/env/vapid.sh                  # one script writes them again

ENV_FILE=/path/to/other.env makes every script write to another file.

First start and first login

just stack dev
  • There is no seed script: every account goes through Keycloak.
  • The first build compiles every service: about 12 minutes on a 12-core laptop.
  • Check the edge is up: curl -i http://localhost/twin/health answers 200.
  • Keycloak’s admin console is at http://localhost:8090, with the KEYCLOAK_ADMIN_* values from .env.
  • The full list of addresses, and how to leave parts out: Run the Application.

A cold build loads the CPU, not memory

  • Measured on a 12-core, 16 GB laptop: just stack dev --build took 728 s, CPU pressure 88–96 % for about eight minutes, free memory never under 7.7 GB.
  • Build steps run under system.slice, so a CPUWeight on docker.slice does not slow them. sudo systemctl set-property user.slice CPUWeight=400 keeps the desktop responsive.
  • COMPOSE_PARALLEL_LIMIT has no effect: the runner always builds with COMPOSE_BAKE=true.

The local cluster, in short

The full path is on Kubernetes & Istio.

StepCommandNote
1Add 127.0.0.1 ambitwin.local to the hosts filejust k8s hosts prints the line. Linux and macOS: /etc/hosts. Windows: C:\Windows\System32\drivers\etc\hosts
2Optional: GHCR_USERNAME, GHCR_TOKEN in .envOnly for private images. The token needs read:packages

4Open http://ambitwin.localSame paths as Compose, Grafana included
  • Keycloak is not deployed in the cluster, so signing in there fails unless a Keycloak is reachable from it.
  • Prometheus has no route: kubectl port-forward reaches it.

Traps

  • A value already in .env is never replaced. Rotating one means deleting its line first. Only RUST_VERSION is written again on every run.
  • Deleting secrets/gateway-dev-key.pem signs everyone out. The next start makes a new key.
  • A lockfile made by a plain npm install on macOS or Windows loses its Linux packages, and CI’s npm ci fails. just setup clean-install makes every Node and Python lockfile again.

Gaps

  • keycloak/README-google.md does not exist, though keycloak.sh points to it. How to set up the “Continue with Google” client is written nowhere.
  • just k8s build likely fails for the six Rust images. Each Dockerfile starts FROM rust-base. Compose provides it as a build context, but the plain docker build in the recipe gives none, and the local image is named ambitwin-rust-base. Read from the files, not run.
  • openssl, k3d, kubectl and Quarkdown have no pin in .mise.toml: each machine has its own version.
