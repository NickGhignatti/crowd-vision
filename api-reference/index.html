API Reference

Every service’s edge surface: HTTP as OpenAPI 3 (rendered by Swagger UI), the Socket.IO feed as AsyncAPI 3. The specs are sources in this repository, at api/*.yaml, and are published alongside this guide — so a spec change ships in the same commit as the handler it describes. They document the edge-facing surface only: internal service-to-service hops and cross-boundary payload shapes are contracts in schemas/, not public APIs.
