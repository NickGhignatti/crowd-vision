Agent

Keywords on this page
WordMeaningExample

HopOne round: the model answers, or asks for a toolHop 1 asks for sensors, hop 2 answers

EmbeddingA list of numbers that stands for a text’s meaningUsed to find similar chunks

TraceA record of every hop and tool, with time and costSent to Langfuse

Realises the Knowledge & Assistance domain, with chat. Python, PostgreSQL with pgvector. Code-level page: Agent Service.

Answers one question at a time: finds the right documentation, fetches live data if needed, writes an answer with citations. Remembers nothing between questions.

Who talks to it

Inside

  • Model, embeddings and reranking are ports. A provider changes behind them, the loop does not.
  • Tools are plugins, like metrics in telemetry. The loop never knows which tool it calls; it asks the registry by name.

The loop

Example. “Is room 2 too hot?” Hop 1: the model asks for room 2’s sensors. Hop 2: with 31 °C in hand, it answers, citing the limits page.

RuleWhy
A hop limitA model stuck calling tools cannot spend time and money forever
Citations checked after writingA citation to a chunk never retrieved is removed, not shown
Streamed and waited answers share one loopThe two cannot drift; only the model call differs
The final answer wins over streamed wordsRemoved citations may already have been streamed

Finding documentation

  • Both searches filter by the person’s rights inside the query. A chunk the person may not read never reaches the model.

Rights, checked twice

WhereChecks
SearchWhich documentation the person may read
ToolsWhich live data the person may read, with Cedar

Neither layer trusts the other to have checked.

  • No admin shortcut. An admin outside an organization is refused its data.
  • Choosing another model costs money, so it needs a high enough role, set by the operator. Without it: 403, never a silent fallback.
  • Auth turned off in dev and test lets everyone in. That is a setting, checked before Cedar.

How it is reached

  • /agent is open at the edge, so evals can call it with their own test token.
  • Both edges strip any claims header on /agent. Otherwise an outside caller could forge one.
  • It is the service that turns model output into calls, so it gets the most care. In the cluster, it is the one service with an Istio rule limiting who may call it.
  • People reach agent through chat, which forwards claims the edge has checked.

Gaps

  • No Prometheus metrics. Traces go to Langfuse only.
  • The reranker does nothing yet. Results are the merged ranking.
