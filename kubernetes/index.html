A request through Istio

StepWhat happens
1The token is read from Authorization: Bearer … or the authentication_token cookie
2jwksUri points at the gateway’s own /gateway/* route, so the key fetch also goes through the mesh
3–4outputPayloadToHeader: x-gateway-claims; forwardOriginalToken: false, so the JWT itself goes no further
5Gated paths need a request principal from issuer cv-gateway
6ReplacePrefixMatch: /, same as Caddy’s handle_path
7–8ztunnel on each node wraps pod-to-pod traffic in mTLS; plain text is refused

Which paths need a token

agent

RuleWhereEffect
Remove x-gateway-claimsagent-route, RequestHeaderModifierThe edge never passes claims to agent
agent-callersistio-agent-authz.ymlOnly ServiceAccounts ambitwin-gateway-istio and chat may open a connection

Why: agent trusts the claims header without a signature. Only chat may hand it one; ztunnel checks the caller’s identity, which a pod cannot fake.

Traps

  • Wrong CNI path, broken node. k3d’s containerd looks for CNI plugins in /bin. Another path makes every pod fail with failed to find plugin "istio-cni", and each failed retry leaks an address until no IP addresses available in range set. Only a new cluster fixes that.
  • Git Bash rewrites /bin. Run straight from Git Bash, istioctl --set values.cni.cniBinDir=/bin gets a Windows path. just runs recipes through PowerShell on Windows, which does not.
  • No Keycloak in the cluster. claims-gateway looks for it at host.k3d.internal:8090, so Keycloak must run from Compose, or sign-in fails at start.
  • A missing token gives a different status. Caddy answers 401 from /verify; Istio’s policy denies a gated path with no principal by its own refusal, not by claims-gateway.
  • An expired cookie may block everything. Istio rejects a request whose token is present but invalid, on any path. The cookie has no Max-Age, so an expired JWT stays in the browser. Not tested here.
  • The cookie is Secure. Browsers keep it over plain http only for localhost, and the cluster is reached at http://ambitwin.local. Not tested here.
  • Image tags drift. grafana is 13.2.4 in Compose and 13.2.1 in the cluster; redis 8.10.2 and 8.10.1.
  • dashboard-secret names contractsdb. dashboard ignores the database in its URI and opens ambitwin anyway.
